# 🚆 KHOJ – Railway Passenger Safety & Assistance System

KHOJ is a web-based platform designed to make railway journeys safer and more convenient by providing passengers with support for **Lost & Found items, Medical Emergencies, and Women's Safety**.

The system connects passengers with volunteers and enables complaints to be submitted, assigned, tracked, and resolved efficiently.

## 🌟 Features

- 🔎 **Lost & Found Assistance** – Report and track lost belongings.
- 🚑 **Medical Assistance** – Request help during medical emergencies.
- 🛡️ **Women's Safety** – Get assistance during unsafe situations.
- 👥 **Volunteer Support** – Connect passengers with available volunteers.
- 📍 **Location-Based Assistance** – Helps identify suitable nearby support.
- 📋 **Complaint Management** – Submit and track complaints.
- 🔐 **Role-Based Access** – Different access for passengers, volunteers, and administrators.
- 📊 **Complaint Tracking** – Monitor the status of requests from submission to resolution.

## 🛠️ Technologies Used

- **Frontend:** Streamlit
- **Backend:** Python / Flask
- **Database:** MySQL
- **Authentication:** Role-Based Authentication
- **Security:** Password Encryption
- **Programming Language:** Python

## ⚙️ System Workflow

1. Passenger registers/logs into the system.
2. Passenger selects the required assistance:
   - Lost & Found
   - Medical Emergency
   - Women's Safety
3. Passenger submits the required details and location.
4. The system identifies suitable volunteer support.
5. Volunteer accepts and handles the request.
6. Passenger can track the complaint status.
7. The request is updated until it is resolved.

## 👥 User Roles

### Passenger
- Register and login
- Submit assistance requests
- Report lost items
- Request medical/safety assistance
- Track complaint status

### Volunteer
- View assigned requests
- Accept assistance requests
- Help passengers
- Update request status

### Administrator
- Manage users and volunteers
- Monitor complaints
- Track request progress
- Manage the overall system

## 🎯 Problem Statement

Railway passengers may face problems such as losing belongings, medical emergencies, or safety concerns. Traditional reporting processes can be slow and difficult to track.

KHOJ provides a centralized digital platform to make reporting, volunteer assistance, and complaint tracking more organized and efficient.
